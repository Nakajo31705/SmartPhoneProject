# Week1障害物よけるゲーム

## 操作
縦線の位置をタップで移動できます。

## ゲームルール
赤いBoxに触れるとゲームオーバーです。

クリア条件はありません。エンドレスです。

ゲームオーバー画面で画面をタップすると再スタートできます。

# Week2モンスト風のゲーム

## 操作
移動させたい方向と逆方向に引っ張る(スワイプ)ことで球を飛ばすことが出来ます。

## ゲームルール
敵を３体倒すとゲームクリアです。
敵のHPは左上にあります。

行動回数があり０になるとゲームオーバーです。

---

# week3隕石を打ち落とすゲーム

## 操作
球を飛ばしたい方向にフリックすると球を飛ばすことが出来ます。

## ゲームルール
画面下に白い床があります。これに隕石が触れるとHPが減ります。0になったらゲームオーバーです。(HPの最大数は３)

ゲームオーバーになる前に隕石に球を当てて先に目標撃墜数を０にするとゲームクリアです。
